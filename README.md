A climate-aware wellness app designed to help users stay hydrated, monitor heat risk, and build safer outdoor habits.

## Features

- Real-time weather integration
- Dynamic heat risk monitoring
- Hydration tracking
- Outdoor session awareness
- Heat exhaustion symptom guidance
- Adaptive environmental UI


## Design Philosophy

HeatSafe was designed as a calm and emotionally supportive wellness experience inspired by Apple Health and modern wellness products.
The goal was to create a climate-aware application that feels human-centered rather than overly technical.


## Built With
